# 冷路径优化：v327 实验记录

目标：在不放宽事实、适用范围、隐私与趣味门槛的前提下，提高普通照片的合格知识产出。不是凭 `ready` 或自评分宣布上线。

冻结输入：授权公开评测集 web-009（电饭煲）、web-021（皂液器）、web-049（漂浮回形针）。保留全部失败。这三张是难例，不代表总体分布。验证改动后使用未参与本轮调优的公开照片作为留出集。

本轮边界：最多两个路线变体、12 张照片尝试；诊断包装器限制累计 100 次模型调用 / 50 万个已报告 Token。余额和真实价格未核验，调用数/Token 上限不是金额硬熔断；不跑全量付费评测，不动生产或手机数据。来源页面读取不发送图片；照片仅发给既有百炼模型。

基准操作：本地真实 `/v1/photo-insights`，全迁移内存 SQLite，无生产动态缓存。主要指标为主审复核合格数；次要指标为各阶段失败原因、时延、Token、搜索调用。每次保留源码 SHA、原始模型输出和工具返回 URL（不记录密钥或图片请求）。这里的主审是 Codex，不是用户人工验收、独立盲评或真人评测。

## 确定性修复（不是第三个提示词变体）

- 六个来源统一收口，保留各组成功原文；只有整体证据仍不足且有临时故障时返回可重试错误。
- 写卡之前给实际读取成功的原文连续编号；仍精确校验引用，不在生成后替模型猜编号。
- 跳转按最终 URL 重算来源权威和发布者，按最终 URL 去重，避免普通站继承官方信用。
- `done` 不等于执行过搜索；工具缺失/失败返回可重试错误，真正空结果单独记录。尊重显式上游零搜索计数。
- 动态缓存版本升级为 `quality-v5-source-scope`，不复用缺少这些范围/来源保护的旧动态卡；人工目录仍保留。未改 iOS 自动重试修订号，未部署。

## 决策与复现

**本轮不批准新提示词上线，也没有“最佳变体”。** 工程缺陷有离线反例与修复证据；检索命中提高不等于知识质量提升。12 次照片尝试全部保留，使用 59 次模型调用、169,128 个上游报告 Token、12 次搜索调用；一轮失败阶段也由本机包装器记录。不等于实际账单或生产失败计费已修复。

新 `evaluation/editorial-regressions-v327.json` 保存 7 个真实失败草稿，明确标注主审为 Codex。它是下一步评审器校准负例，不可嵌入生成提示词来背题，不是发布评测集。先用这些负例检验评审是否还把基础常识、术语替换和范围泛化判为高分；再加入与它们独立的正例/留出集，校准成功后才恢复大规模照片迭代。

本地验证：网关 **40/40**、TypeScript 通过、Cloudflare dry-run 打包通过（未部署）、评测门禁 **4/4**、源码规则通过。iOS 本轮未改、未重新运行；旧 130 项逻辑和 2 条 UI 结果仍只是前一轮证据。真机签名、自动生成、跨日、正式分发和金额硬预算未在此轮解决。
