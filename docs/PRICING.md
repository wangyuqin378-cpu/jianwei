# 见微托管服务定价口径

更新日期：2026-08-26。

## 正式权益

- 每天从未处理过的照片中完成最多 3 张 AI 理解。
- AI 比较候选知识，只发布最有趣的 1 条。
- 每自然月最多发布 31 条知识卡。
- 用户也可选择自带百炼 Qwen API Key，不购买托管服务。

## 单位成本估算

按一位用户连续使用 30 天计算：90 张图片理解、30 次知识择优。

Qwen3.7-Flash 北京区当前公开价为输入 0.2 元/百万 Token、输出 0.8 元/百万 Token（0–32K 请求）。长边 1280 px、约 1280×960 的候选图按官方公式约为 1,202 个图片 Token；90 张图片的纯视觉输入约 10.8 万 Token，即约 ¥0.022。再计入识别提示词、短 JSON 输出、30 次每日择优和少量低置信度 Plus 升级，模型推理常见预算约 ¥0.05–0.15/活跃用户/月。

按当前调用方式拆开看：

| 调用 | 每月次数 | 主要计费量 | 月成本估算 |
| --- | ---: | --- | ---: |
| Qwen3.7-Flash 图片理解 | 90 | 约 10.8 万图片 Token，加提示词与短 JSON 输出 | ¥0.04–0.07 |
| 低置信度升级 Qwen3.7-Plus | 约 5–15 | 仅在置信度低于 0.72 时调用 | ¥0.02–0.08 |
| 每日 3 选 1 | 30 | 只比较已有对象与事实，不重复上传图片 | ¥0.01–0.03 |
| 图片内容安全 | 90 | 官方按量价 15 元/万次 | 约 ¥0.14 |
| 文本安全 | 约 90–120 | 单次不足 1,000 Token 按 1,000 Token 计 | 约 ¥0.04–0.05 |

因此，只有 AI 与安全审核时，常见值约 **¥0.25–0.4/活跃用户/月**；把模型升级、重试、临时存储和计量波动都算进去，采用 **¥0.6/月** 作为日常预算、**¥1/月** 作为熔断上界更稳妥。

北京区 Qwen3.7-Flash 当前还有 100 万 Token 新人免费额度，有效期为开通百炼、模型发布或申请通过三者中较晚日期起 90 天。当前账户充值的 10 元只作为免费额度之后的模型调用余量，不将它视为可以无上限运行的预算。

这个口径基于当前产品实现：AI 识别物件并比较 3 张候选，知识正文只从已审核知识库匹配，不为每张照片临时联网搜索或自由生成事实。若以后增加逐图联网研究，必须另算搜索、长上下文与事实审核成本，不能沿用本表。

预算不只采用理想模型费，还要包含低置信度升级、失败重试、图片内容安全、文本安全、流量和对象存储：

| 成本项 | 预算/活跃用户/月 |
| --- | ---: |
| 视觉理解与每日择优 | ¥0.05–0.15 |
| 图片及文本安全 | ¥0.18–0.25 |
| 临时存储、流量、失败重试 | ¥0.1–0.35 |
| AI 与云端变动成本合计 | **¥0.35–0.75** |

数据库、API 服务和监控属于固定成本。用户很少时摊销会偏高；达到约 1,000 名月活付费用户后，目标总服务成本为 ¥1–2/人/月。成本熔断按 **¥1/活跃用户/月** 的变动成本压力上界和 3 张/天、93 张/月的候选硬额度设置；单个候选任务的预留上界建议为 20,000 micro-CNY（¥0.02）。

按完整变动成本上界估算规模预算：100 名连续活跃用户约 ¥35–75/月，1,000 名约 ¥350–750/月，10,000 名约 ¥3,500–7,500/月；这还不包含低用户量阶段无法摊薄的数据库、日志与监控固定费用。

## 首发价格

- 月订阅：**¥8/月**。
- 年订阅：验证月订阅留存后再增加，建议 **¥58/年**。
- Beta：首批用户免费；正式订阅可配置 7 天试用。

自 2026 年 3 月 15 日起，中国大陆区现行条款的标准佣金为 25%；符合并加入 App Store Small Business Program 时为 12%。因此 ¥8 月订阅按佣金粗算分别到账约 ¥6.00 或 ¥7.04，尚未扣除适用税费和退款。即使按 25% 佣金及 ¥1 变动成本压力上界估算，仍有约 ¥5/付费用户/月的贡献空间。最终到账以 App Store Connect 财务报告为准。

## 调价判断

首版不卖“无限 AI”。连续四周观察真实的单用户调用、低置信度升级率、退款率和 7 日留存：

- 成本超过 ¥2/付费用户/月：先优化图片尺寸、提示词和缓存，不立即涨价。
- 7 日活跃不足 35%：保持 ¥8，先改善内容命中和组件留存。
- 7 日活跃超过 50%，且用户稳定保存或反馈：再测试 ¥10–12/月。
