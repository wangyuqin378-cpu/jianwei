# 隐私与数据保留

生效日期：2026 年 8 月 26 日。

如需询问、删除数据或反馈隐私问题，请通过[见微支持页面](https://github.com/wangyuqin378-cpu/jianwei/blob/main/docs/SUPPORT.md)联系。请勿在公开反馈中附上照片、API Key 或 App Store 交易凭证。

## 默认不上传

- 检测到人脸或自拍标签的图片；
- Screenshots 路径、截图标签或高文字密度图片；
- 证件、票据、银行卡、文档类图片；
- 清晰度不足或近似重复图片；
- 用户加入“本次安装不再分析”列表的图片。

端侧检测不能被描述为绝对保证，因此上传前界面始终说明候选范围，并提供暂停、删除、仅选择照片三种控制。

系统照片选择器或第三方分享的临时 URI 只会在应用内二次确认后复制到私有目录，并改用随机文件名。单图最多 25 MiB、单批最多 100 MiB；敏感、低质或不可恢复失败会立即删除，未完成原始副本最多保留 24 小时。成功卡片会用同一上传管线产生的 1280px 无元数据 JPEG 覆盖原始副本，净化缩略图最多保留 30 天。“清除本地照片索引”会一并删除这些副本，不会删除系统相册原图。

“本次安装不再分析”通过应用内本地标识和当前匿名设备的服务端墓碑阻止后续处理；卸载或清除应用数据会重置本地标识。首版不使用账号、广告 ID 或稳定硬件指纹，因此不承诺跨安装识别同一张照片。

## 服务端数据

- 候选图：分析完成立即删除；服务启动时及每 5 分钟清理过期本地/OSS 对象，并要求 OSS Bucket 同时配置 24 小时生命周期。
- 匿名安装身份：随机生成，不收集手机号、邮箱或广告 ID。
- 全局成本账本：只保存随机事件 ID、时间戳和部署方配置的单任务最坏成本预留额，不保存设备、照片或候选标识；设备数据删除后仍保留，用于限制匿名重装后的全局任务量和人民币预算。预留额是成本上界，不是用户账单。
- 卡片和反馈：用于当前设备的内容排序。
- 自带 Qwen Key：只保存在 iPhone Keychain；分析请求通过 HTTPS 单次使用，服务端不写入数据库、响应或日志。
- App Store 交易：托管服务请求携带 Apple 签名交易，由服务端验证产品、应用、撤销和到期状态；不接触用户的付款资料。
- 删除请求：删除设备、任务、卡片、反馈、追踪项和未过期对象。

## iOS 隐私披露

iOS 包含 `PrivacyInfo.xcprivacy`，申报照片/视频、匿名设备标识和产品交互数据用于 App 功能与内容个性化，全部不用于追踪。由于这些数据在服务端通过匿名安装身份关联，App Store 隐私问卷应保守选择“与用户关联”，不能因为不要求登录就填成“不关联”。

## 禁止用途

照片及推导数据不得用于广告、联系人数据库、人脸身份识别、人物关系推断、健康诊断、情绪/颜值评分或训练第三方模型。

## 内测指标导出

受控 Beta 不自动上传分析指标。测试者可以主动导出本地 JSON 报告，其中只包含计数、时间、
App 版本、设备厂商/型号、Android API 级别和系统构建指纹。报告排除照片、标签、位置、
MediaStore 标识、安装身份和设备凭据，由用户自行决定是否分享以及分享到哪里。
