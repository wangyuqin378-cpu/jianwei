# 隐私与数据保留

本地修订日期：2026 年 9 月 14 日；需随对应版本发布。

如需询问、删除数据或反馈隐私问题，请通过[见微支持页面](https://github.com/wangyuqin378-cpu/jianwei/blob/main/docs/SUPPORT.md)联系。请勿在公开反馈中附上照片或设备凭证。

## 照片如何处理

见微只在用户授权的照片范围内工作。iPhone 会先排除检测到人物、证件、截图、高文字密度、明显模糊、损坏或近似重复的图片。端侧检测不能被描述为绝对保证，因此用户可以随时暂停自动发现、修改系统照片权限、清除本机索引，或请求删除云端数据。

通过本机筛选的候选图会缩至最长边 1280 px、重新编码，并移除 EXIF、位置、设备信息和原文件名。为每个待准备日期最多发送 9 张脱敏候选，用于识别物件、寻找知识并选择该日期的卡片。App 会先准备今天，再逐步补齐未来 6 天；首次补齐七天的前台任务最多分析 63 张，不代表实际一天只会上传 9 张。后台每次执行仍最多分析 9 张，已经准备好的日期不会重复分析。发送路径取决于用户选择的 AI 服务：

- **使用自己的 Qwen Key**：Key 只保存在本机 Keychain；手机通过 HTTPS 直接请求阿里云百炼，不把 Key、候选照片或生成历史发送给见微服务器。不替用户开启联网搜索、不要求额外开通搜索或独立付费审核，也不以平台 Key 兜底。模型调用费用计入用户自己的百炼账号。
- **使用见微托管服务**：手机把脱敏候选发送给见微网关，再由平台 Key 请求百炼。新知识研究使用模型内置联网搜索；搜索问题使用物件名称，不包含照片、相册标识或原文件名。已有已验证通用知识可以复用，费用纳入见微服务成本。

自带 Key 的模型知识卡会标注“AI 生成，未联网核实”，不编造来源；命中已审核知识库的卡片按实际来源标注。模型判断和联网查证都不等于绝对正确，用户可以反馈“识错了”或“太私人”。

为避免反复讲同一知识，自带 Key 的写作和复核请求会附带最多 20 条已保留知识的物件名、标题和正文片段，优先选择与当前物件相关的历史和已准备卡片。此上下文只发给用户 Key 对应的百炼服务，不附带历史照片、卡片 ID、照片日期或个人说明，也不发送给见微服务器；历史内容只用于避重，不作为事实已核实的证据。

见微不把照片保存为云端相册。网关在模型请求期间转发图像，处理完成后不把原图写入对象存储或数据库。App 在本机保存卡片、照片索引、反馈和展示所需的脱敏缩略图；清除本机数据不会删除系统相册原图。

## 服务端保存什么

以下适用于曾使用见微托管服务的用户；仅使用自己的 Key 不会因生成知识而创建见微云端身份。为了鉴权、防止重复计费和控制成本，服务端保存随机安装标识的哈希、随机设备凭证的哈希、请求幂等结果、模型用量和估算成本。幂等结果可能短期包含已经生成的卡片文字、来源和匿名候选 ID，但不包含照片、系统相册 ID、原文件名或精确位置。

新版托管分析还会携带本机已保留知识的去重指纹，帮助跳过很久以前已经给过的事实。指纹根据通用知识主题和正文计算，不携带历史卡片正文、个人说明、照片日期、卡片 ID 或文件名；仅用于当前请求，不写入数据库，也不把指纹集交给模型。通用事实仍可能通过已知内容匹配指纹，因此这不是“绝对匿名”的保证。仅使用自己的 Key 时不发送这些信息给见微服务器。

经过验证、可用于不同用户的通用知识可能写入缓存，其中包含规范化物件主题、事实、来源、质量评分、模型版本和证据摘要；不包含用户照片或相册标识。卡片反馈目前主要保存在本机；服务端反馈接口不建立用户画像。

用户可在设置中清除本机索引、卡片和脱敏缩略图，系统相册原图与本机 Qwen Key 不会被删除。此操作保留既有云端删除凭证；切换为自己的 Key 也不会自动删除过去使用托管服务产生的数据。

“删除见微云端与本机数据”只处理已有的云端身份，不先注册新身份。服务端确认后，App 清除对应设备访问凭证；服务端删除该匿名设备的用量、幂等记录和设备记录，通用知识缓存不属于单个用户数据。若云端未确认删除，仍清除本机照片数据，并明确提示保留凭证供重试。没有本机云端凭证时，不会据此声称供应商或其他安装的数据已删除。

数据删除不自动取消 App Store 订阅、不撤销百炼 API Key，也不删除模型供应商按其条款保留的数据。用户可单独删除本机 Key、在百炼管理 Key，或在 App Store 管理订阅。本机用于购买归属的随机安装标识会保留，避免订阅失去关联。卸载或更换设备前，如需删除见微云端数据，应先在 App 内完成并确认结果。

## 第三方处理与用途

候选照片会由阿里云百炼 Qwen 模型处理。具体处理还受[阿里云百炼隐私说明](https://help.aliyun.com/en/model-studio/privacy-notice)及适用服务协议约束。见微不会把用户照片发送给 Kimi 或 DeepSeek；它们只用于不含真实用户照片的离线公开评测。

见微不接广告 SDK，不追踪用户，不使用照片建立广告画像，也不将照片及推导数据用于人脸身份识别、人物关系推断、健康诊断、情绪或颜值评分。动态知识不覆盖人物、政治时事、健康诊断和高风险安全建议。

## iOS 隐私披露

iOS 包含 `PrivacyInfo.xcprivacy`。App Store Connect 隐私问卷与隐私清单必须如实披露照片或视频数据、匿名设备标识和服务用量数据的实际处理用途；这些数据只用于 App 功能、内容个性化、安全与成本控制，不用于追踪。
