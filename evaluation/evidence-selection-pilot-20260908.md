# 原文片段选择协议：运行前验收定义

目标是消除证据审核时抄错原文导致的可重试502，不降低事实支持标准。此实验独立于失败的主物件疑问提示和机制补充提示，默认生产路径不切换。

- 基线为现网v15的证据审核语义提示；撤回尚未发布的两行机制提示。唯一差异为原文按连续片段编号，模型返回片段ID，服务端从本次请求原文绑定证据，不接收模型重写的引文。
- 本地协议门槛：原文无丢字、无改写；完整分句集合；ID必须属于本次证据；不能混合不同源冒充单一原文；假ID、漏分句、重复片段、结构错误不得通过；明确的负面判定仍是拒绝；旧协议保持不变。
- 实际模型固定14个文本条件：两条真实抄错引文的剪刀/手柄候选，以及此前冻结的12条正确/错误配对。每条一次，不以失败为由重跑；最多14次，无图片、搜索、生产数据写入或发卡。
- 主指标分别记录结构完整率、支持/拒绝与人工预期一致率，不把程序能解析算作事实正确。前两条只评估原文引用完整性，原候选是否值得发布仍需独立人工核对。
- 后续采用条件：12条配对均与预期一致、两条引用样本均得到完整判断、没有错误事实被接受；否则不切换生产。即便达标也不等于照片新卡率、趣味、真机或跨日通过。
- 超时、403等失败如实保留；403停止余下调用。单次最小访问诊断只排查服务状态，不补算评测通过。所有结果、未测条件与成本回执一并保存。
