# App Review 说明

见微不要求登录。首次启动后，审核人员可选择“仅选择照片”，通过系统照片选择器提供一张不含人物、证件或大段文字的日常物件照片。

AI 服务有两条路径：

1. 见微 Pro：商品 ID 为 `cn.jianwei.ios.pro.monthly`，按月自动续订，每天最多分析 3 张候选并发布 1 条知识，每自然月最多 31 条。购买、恢复购买、管理订阅、隐私政策和 Apple 标准使用条款均可从首次引导或设置页访问。
2. 自带 Key：用户可自行填写百炼 Qwen API Key。Key 只保存在本机 Keychain，请求时通过 HTTPS 单次发送给见微后端，服务端不写入数据库、响应或日志。

审核建议使用 Sandbox 购买见微 Pro，无需提供第三方账号。完成购买后选择照片；生成的知识卡会展示识别对象、置信度、推荐原因和来源链接。桌面小组件支持小号和中号。

照片先在设备上进行隐私筛选。人物、截图、证件、高文字密度、模糊和重复图片不会进入上传流程。上传候选会清除元数据并缩小，服务端分析完成后立即删除，最长保留 24 小时。

若审核期间托管服务不可用，请在 Resolution Center 联系开发者；不要要求审核人员提供个人 API Key。
