# App Review 说明

见微不要求登录，当前版本免费使用见微托管的 AI 服务，无需填写 API Key，也不包含 App 内购买。

首次启动后，请选择至少 3 个兴趣方向并授权照片访问。见微会优先发现最近 90 天内尚未处理的照片；候选不足时，再从更早的可见照片中继续寻找，单次最多查看 500 张，不提供逐张手动选图作为主流程。iPhone 会先排除人物、证件、截图、高文字密度、模糊和重复图片；候选图缩小至最长边 1280 px、重新编码并移除元数据后，才通过 HTTPS 发送给见微服务，并进入阿里云百炼 Qwen 模型链路。

每天的准备任务最多发送 9 张候选照片。每张照片会尝试多个可见物件和知识角度，找到最多 3 条达到质量标准且带有来源的知识后停止，再选出最好的一条作为当天主卡。当天没有合格新卡或暂时断网时，App 与小组件继续展示最近一张有效卡片。

知识卡支持换一条、收藏、反馈和可点击来源；所有出现过的卡片都会进入“回顾”。桌面小组件支持小号和中号。设置页可以暂停自动发现、管理照片权限、查看当天聚合处理进度、检测服务连接、清除本机索引，以及请求删除云端匿名设备与用量数据。

服务端不会把照片保存为用户相册，也不会使用照片建立广告画像。模型处理完成后不保留原图；服务端仅保存匿名安装凭证、用量与幂等记录，以及不含照片或相册标识的通用知识缓存。
